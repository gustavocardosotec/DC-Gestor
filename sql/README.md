# Scripts SQL — DC Gestor

Este diretório contém os scripts SQL utilizados no banco de dados **Supabase** (PostgreSQL).

## Estrutura de Arquivos

- `schema.sql`: Definição das tabelas principais (clientes, orçamentos, itens, cotações, lojas, etc.).
- `rls_policies.sql`: Políticas de segurança em nível de linha (Row Level Security).
- `migrations/`: Scripts de alteração e migrações futuras.
