# DC Gestor

Aplicativo web mobile-first para gestão de orçamentos elétricos residenciais.

## Stack
- **Frontend:** HTML5, Tailwind CSS (CDN), JavaScript Vanilla (ES6+)
- **Backend:** Supabase (PostgreSQL + Auth)
- **Deploy:** Vercel
- **Repositório:** https://github.com/gustavocardosotec/DC-Gestor.git


## Funcionalidades
1. Levantamento técnico em campo (offline-first)
2. Cotações comparativas de materiais
3. Geração de orçamentos PDF (fidelidade ao modelo)
4. Autenticação Google OAuth + Email/Senha
5. QR Code Pix dinâmico
6. Integração WhatsApp
